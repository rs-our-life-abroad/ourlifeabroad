# 🇦🇷 Salta, Argentine

**Une étape marquante de notre aventure sud-américaine actuelle.**

Salta, dans le Nord-Ouest argentin, contraste complètement avec Buenos Aires : paysages désertiques, montagnes colorées, et une gastronomie locale (les empanadas salteñas notamment) qu'on ne se lasse pas de tester.

Une région moins fréquentée par les touristes que la Patagonie, mais qui vaut clairement le détour.
